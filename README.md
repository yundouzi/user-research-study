# 岩中花述播客用户研究原型

这是一个面向播客信息设计研究的本地交互网站。当前版本按照三级研究框架组织：

1. **发现需求**：了解用户打开播客平台、发现新内容、判断陌生单集和回访内容时的真实需求。
2. **验证信息价值**：测试单集信息排序、逐层揭露、真实 App 寻找任务，以及五种单集内辅助信息。
3. **确定设计形式**：比较列表、网状、树状、分类四种结构在 5、10、15 期节目下的内容理解与视觉舒适程度。

所有任务开始前会先收集参与者编号、性别、年龄、收听频率、常用平台、播客类型、发现渠道、创作经验和“岩中花述”熟悉程度。需要解释原因或描述体验的问题只标记为“（访谈）”，不要求参与者在网站填写开放文本。

## 本地运行

直接打开 `index.html`，或在项目目录启动本地静态服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

项目不需要安装依赖或执行构建命令。

## 正式实验材料

五个单集内测试支持独立音频文件。请将已获得使用许可的音频放入 `assets/audio/`，并在 `study-materials.js` 的 `audioSources` 中填写相对路径。留空时，网站以演示模式运行，计时、辅助信息和评分流程仍可测试。

如需本地研究者视图，请将 `config.example.js` 复制为 Git 忽略的 `config.js`，再设置仅用于本地原型的访问值。前端访问门槛不是真正的身份认证，不适合保护云端研究数据。

## 数据记录

- 参与者编号自动生成，不要求填写姓名。
- 进度、答案、条件顺序和行为事件保存在浏览器 `localStorage`。
- 完成页和研究者视图支持导出 CSV 与 JSON。
- “重新开始”会清除当前本地记录并建立新的参与者编号。
